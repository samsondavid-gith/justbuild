Answer for you, 24/7.

Session 6 · 30 min  |  Model: a light copy model to draft the Q&A + a free, keyless chat widget

Your chatbot is not a brain - it is you, on repeat. It runs on your page for free, forever, from a list of question-and-answer pairs you write. Cover the top few questions perfectly.

Prompt - draft your Q&A pairs
I run [my business: what it is, who it is for, price, how it works, area covered]. Write me the 10 most common questions a real customer would ask before buying, and a short, friendly answer to each in MY voice. Rules: answers are 1-2 sentences, no jargon, sound like a helpful human not a robot. Include: what it is, price, how to order, delivery/timing, and how to reach a real person. For anything you are unsure of, leave a [fill in] I can complete.
Prompt - turn Q&A into a keyless website widget
Here are my question-and-answer pairs: [paste them]. Build me a small chat widget I can add to my website - bottom-right corner, opens on tap. It must run entirely on the page with NO API key and NO paid service: match the user question to my closest pair and show that answer, offer a few common questions as buttons, and when it does not know, show "Message me on WhatsApp: [number]". Give me code I can paste into my one-page site.

How to use it

  1. Run the first prompt, fill any [fill in] with your real details.
  2. Run the second prompt to turn the pairs into a keyless widget.
  3. Paste the widget into your website; test the buttons and the "does not know" fallback.
  4. Do not over-build. Cover the top few questions perfectly and stop.
Keyless by design: it costs nothing to run and never breaks on a bill. It answers the same questions so you do not have to.
